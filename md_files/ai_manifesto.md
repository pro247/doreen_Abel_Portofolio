## 2. Core Technical Interventions: Prompts vs. Implementations

### A. UI Architecture & Grid Layout Refinements
*   **What I Asked the AI:** *"My profile image inside a fluid split-hero section is ignoring its `max-width` properties and expanding completely across the mobile screen workspace, pushing layout text elements completely out of bounds. How do I constrain it to a 260px circle canvas?"*
*   **How I Used the Feedback:** The AI explained the mechanics of CSS context overrides and recommended using parent bounding frames combined with `object-fit: cover`. I reviewed the logic, manually adjusted my `index.html` structure to wrap the image inside a clean `.hero-avatar-wrapper`, and enforced explicit HTML dimension settings (`width="260" height="260"`) to resolve the layout shifts completely.

### B. Asynchronous Architecture & Cloud API Engineering
*   **What I Asked the AI:** *"How do I connect my local projects webpage interface dynamically to the cloud via the native GitHub REST API loop, and how do I handle network dropouts gracefully without causing an application crash?"*
*   **How I Used the Feedback:** The AI provided a core blueprint for a non-blocking asynchronous JavaScript `fetch()` thread wrapped inside a structural `try/catch` block. I customized this by embedding my precise account target token (`const TARGET_NODE_USER = 'pro247'`), mapping out the exact dynamic card container inputs (`repo.name`, `repo.stargazers_count`), and styling custom crimson error layout modules that display seamlessly when data feeds are interrupted.

### C. Advanced Device Accessibility Constraints
*   **What I Asked the AI:** *"Lighthouse indicates my site requires an explicit fallback layout engine to satisfy users with motion sensitivities. How do I implement `prefers-reduced-motion` to stop transitions instantly?"*
*   **How I Used the Feedback:** The AI detailed the formatting rules for the `prefers-reduced-motion` media feature query. I appended this block at the absolute bottom of my global stylesheet, locking animations to zero durations (`0.01ms !important`). I then successfully simulated and verified the configuration inside Chrome DevTools using the Rendering emulation command matrix.
